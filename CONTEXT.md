Jeu de rythme multijoueur en ligne

projet avec un mvp/core du jeu à faire rapide et ensuite on incrémente le style

pipeline de création de partition (rythme) via une musique sur youtube ou à importer
jeu comme osu/guitar hero ou il faut clicker/appuyer sur un bouton au bon moment => ça fait gagner des points et fait du bruit

Netcode from scratch ? pour la culture et la curiosité
Language pour le backend ? je veux un langugage avec le plus de performance possible mais le moins de frustration possible dans la maintenance (c++ c'est non) 
language pour le front ? je crois qu'on s'en fout un react fera je pense très bien l'affaire

l'idée c'est d'avoir le moins de lag possible et que le jeu puisse accueillir le maximum de joueurs possible dans la même session

pour rendre le jeu plus fun : 
chaque joueur à un personnage qui danse, si le joueur se foire le danseur tombe ou autre animation ( à voir pour mvp ça peut juste être un visage content, moyen ou pas content en fonction du % de reussite de la partition)
score partagé
possibilité de taunt

le but c'est de voir faire une activité (danse) à plusieurs + écouter de la musique ensemble
